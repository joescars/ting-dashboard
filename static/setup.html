Ting Dashboard

Link your Ting account

One-time setup. Your password is used to sign in once and is never stored — only a refresh token stays on this server.

Where do I find the setup code? 
docker compose logs ting | grep -A2 "setup code"

Or read it straight from the mounted data directory: sudo cat data/setup_token.

Your Ting credentials go only to Whisker Labs' Cognito endpoint — never to this dashboard's operator.
